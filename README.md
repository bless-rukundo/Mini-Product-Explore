# Mini Product Explorer

A simple JavaScript project for practicing asynchronous and event-driven programming.

## Features

- Fetch product data from an API
- Display product images, names, and prices
- Search products
- Practice async/await
- Practice Promises
- Practice Promise chaining
- Practice DOM manipulation

## Technologies

- HTML
- CSS
- JavaScript
- Fetch API
- Promises
- Async/Await
- DOM

## API

This project uses the DummyJSON Products API:

https://dummyjson.com/products
